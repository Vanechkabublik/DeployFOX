# Домен панели

Пример: `deploy.example.com → IP VPS`. Купите домен у регистратора или используйте уже принадлежащий вам. Настройки DNS могут находиться у регистратора, хостинга DNS или CDN: смотрите nameservers вашего домена.

1. Откройте управление DNS домена.
2. Добавьте запись типа **A**.
3. В поле Name / Host напишите `deploy` (некоторые панели требуют полное `deploy.example.com`).
4. В поле Value / Address укажите настоящий публичный IPv4 VPS.
5. TTL оставьте 300 секунд или автоматический. TTL — время, на которое DNS-ответ сохраняется у промежуточных серверов.
6. На время проверки выключите проксирование CDN: нужен прямой DNS-ответ сервера.
7. Не добавляйте AAAA, если IPv6 сервера не настроен; неверный IPv6 может мешать HTTPS.
8. Подождите распространения DNS.

В Windows:

```powershell
Resolve-DnsName deploy.example.com -Type A
```

В Ubuntu:

```bash
getent ahostsv4 deploy.example.com
curl -I https://deploy.example.com
sudo ss -ltnp
```

Подставьте ваш домен. Ответ DNS должен содержать IP вашего VPS. Порты 80 и 443 должны быть доступны через firewall VPS и провайдера. Caddy получает сертификат автоматически после появления правильного DNS и возможности проверки домена. Ошибки смотрите:

```bash
sudo docker compose -f docker-compose.prod.yml logs --tail 150 caddy
```

Причины задержки: старый DNS-кеш, ошибочная A/AAAA, закрытый порт, чужой сервис на порту, ограничения центра сертификации. Не пытайтесь исправить это постоянным удалением caddy_data: там хранятся сертификаты и состояние аккаунта ACME.

Адрес панели должен совпадать с `PANEL_DOMAIN` и `PUBLIC_URL` в .env. CSRF-защита проверяет Origin, поэтому не входите в production через IP или другой случайный домен.
