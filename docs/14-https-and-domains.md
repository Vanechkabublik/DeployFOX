# Домены приложений и HTTPS

Для каждого приложения создайте отдельную A-запись, например api.example.com и app.example.com на один IP VPS. Порты контейнеров могут совпадать: наружу их не публикуют, Caddy выбирает контейнер по домену. Домен панели зарезервирован и не может использоваться проектом. Уникальный индекс запрещает повторный домен у проектов.

1. Создайте DNS A-запись по [инструкции](06-connect-domain.md).
2. При создании проекта укажите домен без https://, пути и порта.
3. Приложение должно слушать указанный container port на 0.0.0.0.
4. Выполните Deploy.
5. После healthcheck агент подготовит файл маршрута в общем volume caddy_routes, проверит конфигурацию и выполнит reload.
6. При ошибке проверки/перезагрузки файл предыдущего маршрута восстанавливается; кандидат не становится активным.
7. Откройте `https://ваш-домен` и проверьте сертификат в браузере.

Reverse proxy Caddy поддерживает WebSocket. Наличие SUCCESS означает успешный healthcheck и принятую конфигурацию, но не обязательно уже выпущенный сертификат: ACME выполняется отдельно. В Домены нажмите «Проверить DNS / HTTPS». Для этого SERVER_IP в .env должен содержать настоящий публичный IP VPS. Проверяются DNS, TCP 80/443 и сертификат с правильным ServerName. Это запрос с VPS, а не из независимой внешней сети; при NAT/hairpin результаты могут отличаться. Диагностика:

```bash
sudo docker compose -f docker-compose.prod.yml logs --tail 200 caddy
sudo docker exec deployfox-caddy caddy validate --config /etc/caddy/Caddyfile
curl -vI https://app.example.com
```

Если сертификат не появляется, проверьте A и AAAA, firewall, порты и Caddy logs. Не используйте `curl -k` как подтверждение исправленного HTTPS: этот флаг отключает проверку сертификата.

Для изменения домена откройте проект → Настройки проекта, сохраните новый домен и выполните Deploy. Старый маршрут продолжает работать до успешного переключения и остаётся зарезервированным в БД. Затем старая резервация освобождается. Чтобы отключить публичный домен, сохраните пустое значение и также выполните Deploy. Не редактируйте таблицы/routes вручную без копии и понимания процедуры восстановления.
