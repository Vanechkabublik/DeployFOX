# Первое подключение с Windows

1. Нажмите кнопку Пуск.
2. Напишите `PowerShell`.
3. Откройте Windows PowerShell или Terminal с вкладкой PowerShell.
4. Введите команду, заменив IP и имя пользователя на значения провайдера:

```powershell
ssh root@203.0.113.10
```

5. При первом подключении появится отпечаток ключа сервера, например SHA256. Сравните его с отпечатком в доверенной web console или документации провайдера. В web console сервера можно выполнить:

```bash
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
```

6. Только после совпадения введите `yes` и Enter. Не подтверждайте изменившийся отпечаток без выяснения причины.
7. Введите пароль. **Никакие символы, точки и звёздочки при вводе не отображаются. Это нормально.** Наберите или вставьте пароль и нажмите Enter.
8. Если провайдер дал приватный ключ, сохраните его в закрытой папке и используйте:

```powershell
ssh -i "$env:USERPROFILE\.ssh\vps_key" root@203.0.113.10
```

9. Проверьте, что вы на сервере:

```bash
whoami
hostname
cat /etc/os-release
```

Ожидается ваше имя, имя VPS и Ubuntu 24.04. Теперь команды Linux нужно вводить в этом окне. Для возврата в локальный PowerShell выполните `exit`. Не путайте пароль VPS, пароль SSH-ключа и пароль администратора DeployFox — это разные секреты.

Если команда `ssh` не найдена, установите компонент Windows «Клиент OpenSSH» через Дополнительные компоненты Windows. Не скачивайте SSH-программы из случайных источников.
